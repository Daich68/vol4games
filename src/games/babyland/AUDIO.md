# Записи чтения стихов

Кладите сюда файлы `<ключ>.mp3` по именам категорий:
`hair, top, bottom, shoes, accessories, makeup, secret`.

Обработку делать НЕ надо — она живая, в `sfx.js` (`voiceChain`). Тракт
собран по брифу Ланы, стр. 11: подъём форманты 1.9 кГц и срез низа даёт
«пластиковую куклу», расстройка на четверть тона — «старый синтезатор»,
понижение разрядности до 6 бит — «цифровые артефакты», узкая полоса и
жёсткий предел — «заставку Sega», компрессор 14:1 — «сильную компрессию».

Пишите чисто и ровно: чем суше исходник, тем лучше ложится обработка.
Как только файл появится, субтитры сами начнут идти по его реальному
времени, а не по таймеру. Пока файла нет — игра работает на субтитрах.
